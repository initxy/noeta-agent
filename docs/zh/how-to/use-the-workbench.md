# 使用工作台

**目标：** 用 noeta-agent 干真活 —— 建项目、开会话、控制一轮对话、用好侧边面板。

**开始之前：** 工作台已经跑起来了（`make run` 或 `python -m noeta.agent`，见
[快速开始](../tutorials/quickstart.md)）。下面的一切在离线 mock 模式下都能走通；
想要真实回答，先[接入网关](configure-provider.md)。

## 1. 建一个项目

打开服务地址（默认 <http://127.0.0.1:8000>）。没有登录。

**项目**就是你机器上的一个目录。填名字、一个**已经存在**的目录的绝对路径（或勾选
"帮我创建"），再选**执行层**：

| 执行层 | 含义 |
| --- | --- |
| `local` | agent 的文件与 shell 工具**直接跑在这台机器上**，没有容器，没有授权弹窗。写入被围在项目目录内；**`shell_run` 不受围栏约束** —— 命令能碰你能碰的一切。 |
| `sandbox` | 工具跑在 Docker 容器里，项目目录以 bind mount 方式挂进去。需要本地 Docker daemon；机器上没有时这个选项会被隐藏。 |

表单会明确告诉你两件事，因为它们都会在后面让人意外：

- **这个项目的每个会话共用这一个目录。** 两个活跃会话可能写同一个文件，没有任何锁。
- **执行层在会话开始时就被焊死。** 之后再改，只影响你之后新建的会话。

## 2. 配置 agent（可选）

项目 → **Settings**：

- **General** —— 名字与执行层（放在这里，是因为它是唯一带安全后果的设置，而且不可
  追溯生效）。
- **Agent** —— persona 提示词（会被写进项目目录的 `AGENT.md`；如果那儿已经有一个
  不是本产品写的同名文件，则原样保留）、默认模型与推理强度。
- **Connections** —— 按项目配置的 MCP server：一个 alias 加上 `http`（URL + 头）或
  `stdio`（命令 + 参数 + env），可以只启用部分工具。启用的连接器**每一轮**都会被解析
  进 agent，工具对模型显示为 `mcp__<alias>__<tool>`。凭证只存在服务端，读接口永远
  不会把值返回。
- **Memory** —— 一个记忆开关。记忆以项目为作用域：一个会话写下的笔记，这个项目后续
  的会话能回忆起来，别的项目读不到。**已知缺口：** 这个开关目前被存下来但没有读者，
  记忆工具无论如何都会挂载 —— 见[已知限制](../operations/limitations.md)。
- **Advanced** —— 项目标识，以及删除。删除项目只是把它和它的会话从工作台移除，
  **磁盘上的目录原样保留**。

**Skill** 不需要管理界面：把一个 `SKILL.md` 包放进 `<项目>/.noeta/skills/`，模型会
按需激活它。给一个本进程已经用过的项目新增 skill 需要重启 —— workspace 的 skill
注册表在该 workspace 的引擎首次编译时解析，并在进程内缓存。

## 3. 开一个会话

**New session**，然后开始打字。一轮进行中你会看到流式的正文与推理、工具调用及其结果、
todo 更新、skill 激活、子 agent 卡片 —— 而且全部可重放：中途刷新页面，转录会从事件
日志重新推导出来。

- **提问。** agent 可以停在一个结构化问题上（选项 + 自由文本），会话进入 `waiting`
  直到你回答。等待期间你仍然可以把消息排队。
- **发送 / 插话 / 排队。** 空闲时只有一个 Run 按钮。一轮进行中时，Send 是**插话**
  （就是空闲时那条发送路径，话会汇入正在跑的这一轮），旁边的箭头则是排队；队列会
  合成**一条**消息发出。
- **Stop** 停掉当前这一轮，但**保留对话** —— 下一条消息会带着完整上下文接着同一条流
  跑。键盘上连按两次 `Escape` 等价。Stop 会先清空队列再中断。
- **失败的一轮可以就地重试。** provider 故障会渲染成对话内的提示，输入框仍然可用；
  发一条普通消息就会恢复同一个 task。
- **Edit & retry** 作用在**你自己**的消息上，会 **fork**：在同一个会话里分出一条
  branch，原来的那条完好无损。分支切换器会显示血缘；两条分支共用同一个项目目录 ——
  fork 不会还原文件。
- **附件。** 粘贴或选择 PNG / JPEG / GIF / WebP 图片（每张 ≤ 5 MB，必要时客户端会先
  压缩）。粘贴长文本会折叠成一个 chip 而不是灌满输入框；粘贴链接则插入链接。
- **`/` 命令与 `@` 提及。** `@` 搜索项目里真实存在的文件，`/` 为这条消息钉住一个
  skill。输入框为空时按 `↑` 可以召回之前发过的内容。草稿在刷新后仍在。

## 4. 侧边面板

在窗格标题栏上开关。

- **Files** —— 项目目录，从宿主机侧读取，所以两种执行层都能用，容器停了也能用。
- **Artifacts** —— 转录里指向过的文件，**由服务端核实之后**才会获得标签页。Markdown、
  图片、PDF、HTML 和文档可以打开；文本文件可编辑，保存带乐观锁。如果别人先改了这个
  文件，你会拿到一个冲突，两个选择：**Reload theirs** 或 **Overwrite with mine** ——
  不会静默覆盖，也没有三方合并。表格是只读的。
- **Preview / Terminal**（仅 sandbox 项目）—— 容器自己的浏览器与终端，从**另一个
  origin** 提供。没有运行中的容器时它们会消失，这对 `local` 项目或被回收的容器来说
  是正常的。

## 5. 外壳、标签页与快捷键

- 会话在侧边栏按 **Pinned / Sessions / Archived** 分组；你不在时跑完的会话会带一个
  圆点，正在跑的会话带一个工作指示。删除是行内的两步确认。
- 打开过的会话会保留成**标签页**；一个会话可以**分屏**到第二个窗格。这套布局活在
  浏览器标签页里、随它一起消失 —— 你正在读哪个会话由 URL 说了算。
- `Mod+K` 打开**命令面板**（Escape 先返回上一层，到顶层才关闭）；`Mod+/` 列出全部
  快捷键。

## 6. 出问题的时候

`/trace/<session id>` 是原始事件 trace：该会话各条流及其子任务未经翻译的引擎信封，
按时间排序。它回答的是某一步**为什么**发生，而不只是发生了什么。参见
[排障](../operations/troubleshooting.md)。
